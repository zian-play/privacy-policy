문자리링커 - 문자 · 알림 자동전달

본 개인정보처리방침은 문자리링커 - 문자 · 알림 자동전달 앱(이하 "본 앱")이 사용자의 개인정보를 어떻게 처리하는지에 대해 설명합니다. 본 앱은 사용자의 프라이버시를 최우선으로 생각하며, 불필요한 개인정보를 개발자의 외부 서버로 수집하거나 보관하지 않습니다.

1. 개인정보의 수집 항목 및 수집 방법

본 앱은 별도의 회원가입 절차 없이 사용할 수 있으며, 사용자를 직접 식별할 수 있는 어떠한 개인정보(이름, 이메일, 계정 정보 등)도 개발자의 외부 서버로 수집·전송하지 않습니다.

가. 앱 내부 사용 권한 (디바이스 로컬 국한)

  • SMS 권한 RECEIVE_SMS: 수신된 SMS 문자 메시지의 발신자 번호 및 본문을 감지하여 지정된 전송처로 전달하기 위해 사용됩니다.
  • 전화 권한 READ_PHONE_STATE: 수신 시 디바이스 자체 폰 번호 확인 목적으로 기기 내부에서 참조됩니다.
  • 알림 권한 NotificationListenerService: 스마트폰 상단 알림창에 노출되는 타사 앱(카카오톡, 뱅킹 앱 등)의 알림 메시지를 감지하여 전달하기 위해 사용됩니다.
  • 앱 조회 권한 QUERY_ALL_PACKAGES: 알림창 자동전달 설정 시, 감지할 대상 앱을 직접 선택할 수 있도록 설치된 앱 목록과 아이콘을 화면에 표시하기 위한 목적으로 사용됩니다.

나. 쿠키 및 자동 수집 장치

본 앱은 쿠키(Cookie)를 사용하지 않으며, 일체의 제3자 광고/트래킹 SDK를 탑재하지 않아 어떠한 비식별 기기 정보도 수집하지 않습니다.

2. 개인정보의 이용 목적 및 동작 방식

수집 및 접근된 모든 데이터는 오직 다음의 목적으로만 디바이스 내부에서 처리됩니다.

  • 문자 및 알림 자동전달 기능 수행: 수신된 SMS 및 알림 메시지를 사용자가 직접 설정한 외부 수신처(REST API URL, 텔레그램 봇, 이메일 SMTP)로만 전달합니다. (모든 규칙 검사는 기기 내부에서 동작)

3. 개인정보의 제3자 제공 및 전달

본 앱은 사용자의 개인정보를 제3자에게 판매하거나 마케팅 목적으로 무단 공유하지 않습니다.

가. 사용자가 지정한 수신처로의 전달

본 앱은 사용자가 직접 작성하고 승인한 전달 규칙에 의해서만 작동합니다. 수신된 데이터는 사용자가 지정한 REST API (URL) 또는 이메일(SMTP) 서버로만 전달됩니다.

4. 개인정보의 파기 절차 및 방법

본 앱은 개발자 측에서 별도로 수집 및 보관하는 사용자의 개인정보가 존재하지 않으므로 파기할 대상이 존재하지 않습니다.

  • 사용자의 전송 규칙, 접속 프로필, 전송 내역(로그) 등의 모든 데이터는 오직 사용자의 스마트폰 내부 저장소(Room DB / SharedPreferences)에만 저장됩니다.
  • 사용자가 앱을 삭제하거나 데이터를 초기화할 경우 기기 내 저장된 모든 데이터는 즉시 완전 파기됩니다.
