로그박스 - 알림 자동 전달

본 개인정보처리방침은 로그박스 - 알림 자동 전달 앱(이하 "본 앱")이 사용자의 개인정보를 어떻게 처리하는지에 대해 설명합니다. 본 앱은 사용자의 프라이버시를 최우선으로 생각하며, 불필요한 개인정보를 개발자의 외부 서버로 수집하거나 보관하지 않습니다.

1. 개인정보의 수집 항목 및 수집 방법

본 앱은 별도의 회원가입 절차 없이 사용할 수 있으며, 사용자를 직접 식별할 수 있는 어떠한 개인정보(이름, 이메일, 계정 정보 등)도 개발자의 외부 서버로 수집·전송하지 않습니다.

가. 앱 내부 사용 권한 (디바이스 로컬 국한)

  • 알림 접근 NotificationListenerService: 사용자가 시스템 설정에서 직접 허용한 경우에만, 사용자가 전달 대상으로 선택한 앱의 알림(앱 이름, 알림 제목, 알림 내용, 수신 시각)을 읽어 사용자가 지정한 수신처로 전달하기 위해 사용됩니다. 설정에서 언제든 허용을 해제할 수 있으며, 해제하면 전달이 중단됩니다.
  • 전화번호 사용자 입력(선택): 규칙별로 사용자가 직접 입력한 전화번호는 어느 폰의 알림인지 구분하도록 전달 내용과 함께 사용자가 지정한 수신처로 전송됩니다. 앱은 기기의 전화번호를 자동으로 읽지 않으며, 입력하지 않으면 전송하지 않습니다.
  • 알림 표시 POST_NOTIFICATIONS: 전달 완료 및 상시 대기 상태를 알림으로 표시하기 위해 사용됩니다.
  • 네트워크 INTERNET: 사용자가 지정한 REST API 또는 이메일(SMTP) 서버로 전달 내용을 전송하기 위해 사용됩니다.
  • 백그라운드 FOREGROUND_SERVICE, RECEIVE_BOOT_COMPLETED: 사용자가 상시 대기 모드를 켠 경우 알림 전달이 중단되지 않도록 하고, 기기 재부팅 후 대기 상태를 복구하기 위해 사용됩니다.

본 앱은 문자(SMS) 수신·읽기 권한, 전화 상태 권한, 설치된 앱 전체 목록 조회 권한을 사용하지 않습니다. 대상 앱 선택 화면에는 기기에서 실행 가능한 앱(런처 앱)의 이름과 아이콘만 표시되며 외부로 전송되지 않습니다.

나. 쿠키 및 자동 수집 장치

본 앱은 쿠키(Cookie)를 사용하지 않으며, 일체의 제3자 광고/트래킹 SDK를 탑재하지 않아 어떠한 비식별 기기 정보도 수집하지 않습니다.

2. 개인정보의 이용 목적 및 동작 방식

수집 및 접근된 모든 데이터는 오직 다음의 목적으로만 디바이스 내부에서 처리됩니다.

  • 알림 자동 전달 기능 수행: 사용자가 선택한 앱의 알림 중 사용자가 직접 설정한 조건(인식 단어)에 맞는 알림의 정보(앱 이름, 제목, 내용, 수신 시각)를 사용자가 지정한 외부 수신처(REST API URL 또는 이메일 SMTP)로만 전달합니다. (규칙 검사는 기기 내부에서 동작)

3. 개인정보의 제3자 제공 및 전달

본 앱은 사용자의 개인정보를 제3자에게 판매하거나 마케팅 목적으로 무단 공유하지 않습니다.

가. 사용자가 지정한 수신처로의 전달

본 앱은 사용자가 직접 작성하고 승인한 전달 규칙에 의해서만 작동합니다. 전달되는 데이터는 사용자가 지정한 REST API (URL) 또는 이메일(SMTP) 서버로만 전송되며, 개발자의 서버를 거치지 않습니다. 알림에는 인증번호 등 민감한 정보가 포함될 수 있으므로, 신뢰할 수 있는 수신처만 지정해 주세요. 암호화되지 않은 HTTP 주소로 전송하려면 사용자가 서버별로 별도 확인을 거쳐야 하며, HTTPS 사용을 권장합니다.

4. 개인정보의 파기 절차 및 방법

본 앱은 개발자 측에서 별도로 수집 및 보관하는 사용자의 개인정보가 존재하지 않으므로 파기할 대상이 존재하지 않습니다.

  • 사용자의 전송 규칙, 접속 프로필, 전송 내역(로그) 등의 모든 데이터는 오직 사용자의 스마트폰 내부 저장소(Room DB / SharedPreferences)에만 저장됩니다.
  • 사용자가 앱을 삭제하거나 데이터를 초기화할 경우 기기 내 저장된 모든 데이터는 즉시 완전 파기됩니다.
